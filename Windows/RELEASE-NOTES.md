# SendFile over WiFi — v1.0

## Windows

- Native WinUI 3 application for Windows 10 1809+ and Windows 11.
- Self-contained packages for x64 and ARM64.
- Local IPv4 Wi-Fi discovery, mutual TLS 1.3, four-character SAS confirmation,
  trusted devices, batch transfer and resumption.
- No telemetry, analytics or external data transfer.

Первый выпуск Windows-приложения.
