# SendFile over WiFi — Web

В этом каталоге будет расположен публичный сайт SendFile over WiFi: описание
нативных приложений и страница загрузки официальных сборок.

Это не Web-версия приложения. Сайт не участвует в передаче файлов по локальной
сети и не реализует протокол обмена.

## Локальная разработка

```bash
npm install
npm run dev
```

Перед сборкой `npm run build` копирует канонический каталог переводов из
`../localization/ui.json`, общий `../logo.png` и создаёт статический каталог
`dist`.
Контейнер получает подготовленную копию `src/data/ui.json`; перед его
развёртыванием обязательно выполняется `npm run sync-localization`.

## Развёртывание

`compose.yml` запускает самостоятельный контейнер `sendfile-web` в общей сети
внешнего Caddy. В его конфигурацию добавляется содержимое `Caddyfile.snippet`.

## Приватная статистика загрузок

На сервере `plusap` обработчик журнала загрузок запускается через cron каждые
15 минут. Он учитывает только официальные файлы из `/downloads/` и доступен
только по SSH. Отчёт за последние 30 дней:

```bash
ssh plusap /opt/sendfile-web/scripts/download-report.py
```

Отчёт за другой период от 1 до 90 дней, например за 90 дней:

```bash
ssh plusap /opt/sendfile-web/scripts/download-report.py --days 90
```

В отчёте показываются число HTTP-запросов, число полных ответов сервера и
уникальные посетители. Полный ответ означает, что сервер отдал файл целиком,
но не подтверждает установку приложения. Открытые IP-адреса не сохраняются в
SQLite: после обработки остаются только HMAC-хеши не более чем на 90 дней.
Геолокация отключена; данные не передаются сторонним аналитическим сервисам.
