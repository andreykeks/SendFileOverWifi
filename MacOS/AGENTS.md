# macOS

Здесь фиксируются только macOS-специфичные решения: используемый стек,
песочница и разрешения, сборка, распространение и особенности macOS API.

## Сборка

Результаты macOS-сборки и Derived Data размещаются в `MacOS/build`; они не
добавляются в Git.

## Песочница и сеть

Для обмена по протоколу v1 macOS-цель включает sandbox-разрешения исходящих и
входящих сетевых соединений. В настройках Xcode для этого используются
`ENABLE_OUTGOING_NETWORK_CONNECTIONS=YES` и
`ENABLE_INCOMING_NETWORK_CONNECTIONS=YES`; устаревшие либо произвольные ключи
сборки не создают entitlement. Пользовательский выбор файлов выполняется через
security-scoped URL, предоставляемые системной панелью открытия файлов. Доступ к каждому выбранному URL открывается на всё время
подготовки и отправки (включая вычисление SHA-256), затем закрывается.
Для выбора файлов на отправку используется `NSOpenPanel` с явно включённым
`allowsMultipleSelection`, поэтому пользователь может выбрать набор файлов
через Shift или Command.

## Каталог приёма

В настройках macOS предоставляется настройка каталога загрузки полученных
файлов. Значение по умолчанию — `~/Downloads`.

После успешного получения хотя бы одного файла в нижней части блока
«ПОЛУЧЕНИЕ» отображается кнопка «Показать файлы». Она открывает этот каталог
в Finder.

Настройка «Сохранять дату файлов» выключена по умолчанию и управляет попыткой сохранить переданные
`createdAt`, `modifiedAt` и `mimeType`. Отдельного переключателя атрибутов
нет: права, флаги `readOnly` и `hidden`, ACL, quarantine и расширенные
атрибуты между устройствами не передаются.

## Локализация

Интерфейс поддерживает `en`, `ru`, `it`, `es`, `pt` и `cn`. Пустое значение
локальной настройки языка означает автоматический выбор: используется первая
поддерживаемая системная локаль, а при невозможности её определить — `en`.
Пользователь может выбрать язык вручную либо вернуть значение «Автоматически».
